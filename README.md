### Compile & run 

Using gcc:
```bash
  g++ <file_name> -o run && ./run
```

Using clang:
```bash
  clang++ <file_name> -o run && ./run
```

> NOTE
> Note: the file names are the problem names in [codeforces](https://www.codeforces.com)
